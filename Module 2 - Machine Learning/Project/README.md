# Final Project — Personal Loan Campaign

Summary

This is the capstone project for Module 2. The goal is to analyze and model a personal loan campaign dataset to predict customer response/loan approval and derive business recommendations.

Key files

- `Machine_Learning_Project_Personal_Loan_Campaign (1).ipynb` — Analysis notebook with data preprocessing, feature engineering, model building, and evaluation.
- `Loan_Modelling (1).csv` — Primary dataset used for modeling.
- `Machine_Learning_Project_Personal_Loan_Campaign (2).html` — HTML export of the final report (suitable to share with recruiters).

How to run

1. Install packages as described in Week 1.
2. Open the notebook and run cells in order. The HTML file can be opened in a browser for a static view.

Highlights to mention to recruiters

- End-to-end project: data cleaning, feature engineering, model selection (tried multiple algorithms), performance evaluation, and business insights.
- Delivered an HTML report summarizing methodology, key results, and actionable recommendations for a loan campaign.

Skills & Tools

- Python, pandas, scikit-learn, model evaluation, feature engineering, Jupyter, report export
