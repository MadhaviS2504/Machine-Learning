# Module 2 — Machine Learning (Course Showcase)

This folder contains the deliverables and notebooks from Module 2 (Machine Learning). Use these READMEs to quickly show recruiters the work you completed each week and the final project.

Structure:

- `Week1 - Linear Regression/` — Notebooks and exercises covering simple and multiple linear regression.
- `Week2 - Decision Trees/` — Decision tree notebooks, case studies, and related datasets.
- `Week 3 - Clustering/` — K-Means clustering notebook and segmentation dataset.
- `Project/` — Final project (Personal Loan Campaign) with notebooks, data, and an HTML report.

How to present this repository to recruiters:

1. Start with this README and the `Project/` folder to show a complete end-to-end example.
2. Open the key notebooks in `Week1 - Linear Regression` and `Week2 - Decision Trees` to demonstrate your hands-on skills.
3. Mention tools: `Python`, `pandas`, `scikit-learn`, `matplotlib`, `seaborn`, `Jupyter`.
