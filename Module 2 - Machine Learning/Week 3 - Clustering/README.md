# Week 3 — Clustering

Summary

This week covers unsupervised learning with K-Means and hierarchical clustering, cluster evaluation metrics, and customer segmentation examples.

Key files

- `Hands_on_K_Means_Clustering_Notebook.ipynb` — Notebook demonstrating K-Means clustering and visualization.
- `retail_customer_segmentation.csv` — Example dataset used for segmentation.
- `QUICK RECAP- Week 3 - Clustering.docx` — Summary notes.

How to run

Open the notebook in Jupyter after installing packages from Week 1.

Highlights to mention to recruiters

- Performed customer segmentation and interpreted cluster characteristics to inform marketing actions.
- Visualized clusters and evaluated cluster quality using silhouette score.

Skills & Tools

- K-Means, clustering metrics, scikit-learn, data visualization
