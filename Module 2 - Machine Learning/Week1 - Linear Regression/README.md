# Week 1 — Linear Regression

Summary

This week covers exploratory data analysis (EDA) and building linear regression models (simple and multiple). The notebooks demonstrate dataset cleaning, feature engineering, model training, evaluation (RMSE, MAE, R^2), and residual analysis.

Key files

- `Hands_on_Linear_Regression_Notebook.ipynb` — Main walkthrough with EDA and modeling on example datasets.
- `Linear Regression_ Practice Quiz/PracticeSet-week1.ipynb` — Practice problems and solutions.
- `Practice Exercise 1/SLR_W1_PracticeExercise_Question.ipynb` and `SLR_W1_PracticeExercise_Solution.ipynb` — Guided exercises using `boston.csv`.
- `MLS - Linear regresion/ML_MLS1_Cars4u_Notebook.ipynb` — Additional case study on car prices.

How to run

1. Create a virtual environment and install common packages:

```bash
python -m venv venv
venv\Scripts\activate
pip install jupyter pandas numpy scikit-learn matplotlib seaborn
```

2. Launch Jupyter: `jupyter notebook` and open the `.ipynb` files.
