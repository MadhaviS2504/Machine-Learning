# Module 2 - Machine Learning

This repository contains weekly labs and projects for Module 2 (Machine Learning).

Overview:

- Week 1 - Linear Regression: Basics of regression, dataset exploration, and model building.
- Week 2 - Decision Tree: Decision tree models, feature importance, and evaluation.
- Week 3 - Clustering: Unsupervised learning with clustering algorithms and analysis.
- Week 4 - Project: Capstone-style project combining techniques from prior weeks.

How to use:

- Browse each week's folder for notebooks, scripts, and datasets.
- Each week contains a README.md describing that week's contents and highlights.

If this repository already had a README, its title has been preserved and merged here.
